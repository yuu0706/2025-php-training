・本プロジェクトについて
本プロジェクトは、ブラウザ上で動作するToDoリストを作成するプロジェクトです。
ToDoリストの項目は、「番号」「タイトル」「内容」「作成日」「更新日」となっており、
項目の追加、編集、削除が可能です。

・インストール方法 
1.下記 URL からリポジトリのページに遷移し、[<>code]をクリックする。
  https://github.com/yuu0706/2025-php-training#

2.HTTPS を選択し、URL 横のコピーボタンを押してリポジトリの URL をコピーする。

3.コマンドプロンプト(mac の場合はターミナル)を開く。

4.リポジトリのクローン先にしたいディレクトリに移動する。

5.「git clone」と入力し、コピーした URL を貼り付ける。
  git clone https://github.com/yuu0706/2025-php-training.git

6.ENTER キーを押して、コマンドを実行する。
